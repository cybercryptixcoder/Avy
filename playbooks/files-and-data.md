# Files and data
Working with his files, spreadsheets and data: compute, don't estimate.

1. Read what's there before saying anything about it: read_file (with offset for big files), or python to load it
   (csv, json, pandas if installed) and print its shape, columns and a few rows.
2. Every number you report comes from code you ran: counts, sums, averages, dates, percentages. Show the one line that
   matters, not the whole table.
3. Write results as files in your workspace when he'll want to keep them (a cleaned CSV, a chart, a script), and say
   where they are.
4. Don't change his originals. Work on a copy in the workspace unless he asks you to change the file itself.
